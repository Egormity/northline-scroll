# Third-party software and references

Northline is an original example website built with open-source dependencies. It is not a copy of a complete third-party example application. The website's media has separate provenance and license terms; see [docs/assets.md](docs/assets.md) and the downloadable media credits.

- [React](https://github.com/facebook/react): MIT; user interface components.
- [Lenis](https://github.com/darkroomengineering/lenis): MIT; smoothing over native page scrolling.
- [Lucide](https://github.com/lucide-icons/lucide): ISC; interface icons. See package license for individual icon provenance.
- [Vite](https://github.com/vitejs/vite): MIT; build and development tooling.
- [TypeScript](https://github.com/microsoft/TypeScript): Apache-2.0; development tooling.
- [Vitest](https://github.com/vitest-dev/vitest): MIT; unit testing.
- [Playwright](https://github.com/microsoft/playwright): Apache-2.0; browser testing.

Dependency packages include their license and copyright files. Retain these notices when redistributing dependencies. Python's standard library supplies the local static server and desktop launcher.

The design follows the guidance developed for Amazi's Scroll-driven websites skill, informed by [Scroll Craft](https://github.com/nateherkai/scroll-craft). Lenis integration follows its [official documentation](https://github.com/darkroomengineering/lenis#setup). No Scroll Craft engine or plugin is bundled.
